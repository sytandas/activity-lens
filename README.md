# ActivityLens (AL)

ActivityLens enhances your workout data with insights that aren't available at a glance. It combines weather conditions, calculated effort metrics, and workout analysis to help you better understand your training.

## Motivation

I wanted to see more useful information about my workouts without opening every activity. The goal is to provide meaningful context—such as weather conditions, effort metrics, and split data—directly where it's most useful.
As a log manager and race/tt effort analysis - what will work at which condition at easy level, not junk output as strava is the goal. 

## Features

- 🌡️ Display weather information, including dew point.
- 📈 Calculate relative effort metrics.
- 🏃 View workout splits without opening each activity.
- 🔍 Quickly review activities from a single dashboard and foucs on goal and today's work.
